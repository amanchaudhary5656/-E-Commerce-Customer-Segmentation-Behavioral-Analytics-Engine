# 🛒 E-Commerce Customer Behavior & RFM Analytics Engine

An algorithmic behavioral analytics pipeline developed to process, clean, and segment e-commerce transaction logs using core Python data science libraries. This project implements a **Recency, Frequency, and Monetary (RFM)** cohort segmentation model from scratch utilizing mathematical quantile scaling, completely bypassing high-level machine learning frameworks to focus on core logic optimization.

---

## 📌 Key Features
* **Automated Data Aggregation:** Utilizes **Pandas** to transform transactional logs into structured data arrays capturing customer purchase velocity and lifecycle value.
* **Algorithmic Scoring From Scratch:** Implements statistical quartile distribution boundaries utilizing pure **NumPy** matrix math to systematically classify customer behaviors.
* **Dynamic Customer Segmentation:** Programmatically groups users into actionable marketing cohorts: *VIP Champions, Loyal Customers, At-Risk Customers,* and *Lost Customers*.
* **Executive Visualization Dashboard:** Generates multi-panel data plots via **Matplotlib** mapping customer density distribution against revenue generation metrics.

---

## 🛠️ Tech Stack & Architecture
* **Language:** Python 3.x
* **Data Processing & Engineering:** Pandas
* **Mathematical Operations:** NumPy
* **Data Visualization:** Matplotlib
